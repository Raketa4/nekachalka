# Редизайн сайта «Некачалка» — дизайн-спека

Дата: 2026-09-05

## Цель

Оригинал — Taplink-страница https://taplink.cc/nekachalka (фитнес-студия «Некачалка», Санкт-Петербург). Задача: построить демо современного сайта на основе того же контента, чтобы показать владелице студии (ИП Попова Ольга Сергеевна), каким может быть сайт вместо конструктора-визитки. Это питч-демо, не боевой продакшн: реальный запуск возможен позже, если студия согласится, но уже сейчас все функциональные ссылки (запись, оплата, расписание) должны реально работать, поскольку демо тем убедительнее, чем меньше в нём выглядит «бутафории».

## Анализ оригинала: нет кастомного бэкенда

Всё взаимодействие с клиентом идёт через сторонние сервисы, отдельный бэкенд с нуля не нужен:

| Запись (альтернатива) | `whatsapp://send?phone=79992161077&text=...` | Диплинк в WhatsApp |
| Вопрос в Max | `https://max.ru/u/89992161077` | Мессенджер Max |

| Расписание групповых | `https://r557443.mobi.fitness/` | Виджет стороннего сервиса MobiFitness (CRM для фитнес-студий) |
| Покупка абонемента | `https://taplink.cc/nekachalka/m/` и `.../o/<id>/` | Встроенный магазин Taplink, 23 реальных товара с оплатой |

Отличие от оригинала — только более надёжный формат ссылок на мессенджеры: `https://t.me/nekachalka` вместо `tg://resolve?...` и `https://wa.me/79992161077` вместо `whatsapp://send?...` (те же диплинки, но открываются и на десктопе, и без установленного приложения).

## Информационная архитектура

### `index.html`
1. **Hero** — лого + название, заголовок «Пространство твоих достижений», подзаголовок «Прокачиваем тело и сознание», список услуг (Фитнес / Танцы / Растяжка / Пилатес / Бокс), основной CTA «Пробное занятие в подарок» с ценой от 600 ₽, ссылки на Telegram/WhatsApp
2. **О пространстве** — абзац из оригинала о «спортивной семье» (без сворачивания на десктопе; на мобильном можно оставить как есть, без `+`-раскрытия — текст короткий)
3. **Услуги** — 3 карточки: Персональные тренировки, Групповые (до 10 человек), Сплит-тренировки — с ценой «от» и CTA на запись
4. **До / После** — сетка из 2 реальных фото клиентов с подписями дат
5. **Цены (превью)** — по одной цифре «от» на каждый тип тренировки + кнопка «Смотреть все тарифы» → `pricing.html`
6. **Отзывы** — рейтинг 5.0, ссылка на реальные отзывы на Яндекс.Картах
7. **Контакты / запись** — Telegram, WhatsApp, Max, телефон, расписание (MobiFitness), соцсети (Instagram, VK)
8. **Футер** — реквизиты ИП Попова Ольга Сергеевна, ИНН 420216779496, ОГРНИП 323420500010682, ссылка на договор оферты (Google Docs)

### `pricing.html`
Полный прайс-лист, 23 позиции из магазина Taplink, сгруппированные в 3 блока/вкладки:
- **Групповые тренировки**: пробная 600₽ (было 1200₽), разовая 1100₽, пакеты 4/8/12/16/24/32/64 — 3590/6790/8990/11190/15590/19190/35190₽
- **Персональные тренировки**: пробная 1000₽ (было 2200₽), разовая 2100₽, пакеты 4/8/12/16/24/32/64 — 7990/14390/20390/25590/35990/44790/83190₽
- **Сплит-тренировки**: пробная 1300₽ (было 2600₽), разовая 2600₽, пакеты 4/8/12 — 9190/17590/25190₽
- **Мастер-класс**: 2000₽ (разово, без пакетов)

Каждая позиция — карточка/строка с кнопкой «Купить», ведущей на реальную ссылку оплаты Taplink (`https://taplink.cc/nekachalka/o/<id>/`).

## Визуальная система

- **Палитра**: фон `#F7F4EF` (тёплый кремовый), текст `#2A2724` (графит, не чистый чёрный), акцент `#C1663C` (приглушённая терракота), тёмно-графитовые блоки `#2A2724`/`#332F2B` для контраста (hero-подложка, футер)
- **Типографика**: заголовки/лого — экспрессивный сжатый шрифт с характером (в духе Bebas Neue/Anton, но без грандж-текстуры оригинала — это премиализирует бренд); основной текст — гуманистический сан-сериф с хорошей кириллицей (Inter/Manrope), подключается через Google Fonts
- **Общее ощущение**: много воздуха, крупные фотографии без агрессивных фильтров, скруглённые карточки, мягкие тени вместо жёстких рамок — контраст с тесной мобильной Taplink-вёрсткой
- **Адаптивность**: mobile-first, брейкпоинты минимум для телефона (~375–480px), планшета (~768px) и десктопа (~1200px+); все секции, галерея «до/после» и таблицы цен должны корректно читаться на обоих концах диапазона — это явное требование пользователя, проверяется вручную в браузере на нескольких ширинах перед сдачей

## Технологии и деплой

- Статический HTML/CSS/JS без сборки и зависимостей, по аналогии с `raketa4.github.io` и `Alina_web`
- Структура файлов: `index.html`, `pricing.html`, `css/style.css`, `js/main.js` (если понадобится — например, для вкладок прайса или галереи), `assets/images/`
- Изображения "до/после" и логотип копируются из `source/images/` в `assets/images/` проекта в оптимизированном виде
- Реальные внешние ссылки (мессенджеры, MobiFitness, магазин Taplink, Яндекс.Карты, Google Docs договор) встраиваются как есть/в улучшенном формате — см. таблицу выше
- Деплой (GitHub Pages или иной хостинг) — по факту не входит в эту итерацию; репозиторий `nekachalka` создан и инициализирован (`git init` выполнен), удалённый репозиторий пока не подключён

## Вне рамок задачи

- Разработка собственного бэкенда для записи/оплаты/CRM — не требуется, всё уже покрыто внешними сервисами
- Личный кабинет клиента, авторизация — отсутствуют и в оригинале
- Реальная интеграция виджета MobiFitness (iframe) — просто ссылка-переход, как в оригинале
- Публикация/деплой на реальный домен — обсуждается отдельно после согласования демо с владелицей студии
